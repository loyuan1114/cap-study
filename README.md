# 會考學習資料庫

國中會考完整學習資源，包含歷屆試題、課本講義、重點筆記等，一起加油！

## 內容

| 分類 | 檔案數 | 說明 |
|------|--------|------|
| 會考歷史題 | 30 | 110～115 年歷屆考題 |
| 課本 | 395 | 各學年課本教材 |
| 習作 | 294 | 各科習作練習 |
| 會考題庫+講義 | 1750 | 歷屆題庫與講義彙整 |
| 重點筆記 | 12 | 各科重點整理（內嵌於 index.html） |

共 2481 個檔案：四個分類透過 Google Drive 雲端載入並在頁面內預覽，重點筆記已全部內嵌於單一 `index.html` 檔案中。

## 使用方式

只需 `index.html` 一個檔案即可瀏覽全部內容，無需後端服務、無需其他資源檔。

## 部署到 GitHub Pages

1. 建立 GitHub Repository
2. 將此資料夾推送到 repo
3. 到 Settings → Pages → 選擇 branch (main) 並儲存
4. 網站將發佈至 `https://<username>.github.io/<repo>/`

## 資料存放與安全設計

本專案在設計上刻意讓「程式碼」與「檔案」分離，以降低風險：

- **GitHub 上只有程式碼與自製重點筆記**：課本、習作、考題等檔案一律不上傳 GitHub，僅以連結方式指向個人 Google Drive，於頁面內預覽。
- **`.gitignore` 已排除 `pdfs/`**：即使本機存有 PDF 教材，也不會被誤推上傳。
- **介面不設下載入口**：全部透過頁內預覽檢視，不做檔案散布。
- **可隨時急停**：在 Google Drive 將共用設定改為「封鎖」或撤銷分享後，網站上的雲端分類會立即失效，等同遠端開關。
- **不含金鑰與個資**：程式碼中沒有任何 API 金鑰、帳密、個人資訊。
- **純靜態、不蒐集資料**：無後端伺服器、不使用 Cookie、無追蹤分析工具，僅會向 Google Fonts 與 Google Drive 發出一般資源請求。
- **分享權限請設「知道連結的任何人可檢視」**：切勿開放「任何人可編輯」；若想更保守，可將 repo 設為 Private，僅把網址給同學。
